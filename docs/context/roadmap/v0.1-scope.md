# v0.1 scope (frozen)

The product contract for the first usable version. Changes here are deliberate scope decisions,
not drive-by edits.

## In

- Native iPhone app (SwiftUI, Swift 6)
- Sign in with Apple
- Persistent cloud progress
- **40 puzzles** — 5 tracks × 8 puzzles
- **4 interaction types** — slot selection, minimal edit, block arrangement, best solution
- Linear progression (finish one, unlock next)
- Compile and evaluate remotely; score against best-known
- Retry for a better score (Solved / Fluent / Optimal)
- Hint and explanation per puzzle
- Offline viewing, online evaluation
- Personal best tracking

## Out (explicitly excluded from v0.1)

- Android
- Leaderboards
- Subscriptions / payments
- AI tutor
- User-generated puzzles
- Arbitrary code editor / free typing
- Multiple programming languages
- Complex achievements, XP, coins, badges

## The five tracks

```text
Move or borrow · Remove the clone · Repair the lifetime · Build the iterator · Design the API
```

## Milestones (in order, each gated on the previous)

1. **Five polished puzzles running natively on the iPhone, no login, mocked local evaluator.**
   Gate: the loop is voluntarily fun ("five puzzles from the toilet" test). If not, fix the
   interaction — do not build auth or infrastructure.
2. **The same five puzzles evaluated by the real remote Rust compiler.**
3. **Sign in with Apple; reinstall the app; verified progress returns.**

Only after milestone 3 does content scale from 5 to 40 puzzles. This order minimises wasted
engineering while keeping auth and durable user data core architecture, not an afterthought.

## Name reservations (do early)

Choose the public name (**RustChap**) early enough to reserve: GitHub org/repo, bundle identifier,
domain, App Store name, API domain.
